Where does Gemma keep Dhivehi? Part 2: write it in Thaana first

October 7, 2026 · 7 min read

Summary. Part 1 found that Gemma 4 understands Dhivehi in Thaana script. It does not understand Dhivehi typed in Latin letters, and most people text in Latin letters. Part 1.6 moved the Latin closer to the Thaana inside the model. In this part, the model writes each message in Thaana before it answers. On 200 held-out Latin-typed chat messages, it gets the gist of 87%. Gemini Flash gets 91.5%. Our model fully understands 48% of the messages, and Flash fully understands 69%. Flash is the best Dhivehi model that we measured.

Most Dhivehi on phones is typed in Latin letters, for example kn irakah tha, vvv reethi and mashah neynge. Gemma 4 can't read this. It can read Thaana. We trained it to write the message in Thaana first, and then answer.

Synthetic chat taught the reply format

GPT-6.1 sol wrote 11,500 short messages that a Maldivian might send to an assistant. Each message has its Thaana original, an English meaning and a good reply. A second model typed each message again in Latin, in two or three different ways.

Gemma learned the format of a Dhivehi reply. Replies in Thaana went from 20% to 95%. Replies in Sinhala went from 38 in 120 to one. Full understanding did not change much. We asked about last night's football, and it said that late games are bad for your sleep.

Flash's thoughts taught it to guess

Gemini Flash shows a summary of its thinking. It names the language, gives the meaning of each word, lists what it can't know, and then answers. We trained Gemma on 4,500 of these thoughts. Gemma learned to give word meanings, but the meanings were often wrong. A word-by-word meaning is only correct if the model knows the words.

Thaana first taught it to read

Part 1 found that Gemma understands Thaana. Inside the model, a Thaana sentence and its English translation have similar representations. Latin-typed Dhivehi does not get there. The knowledge is in the weights, but Latin letters don't reach it in one step. So the model now does two steps. First it writes the message in Thaana. Then it reads the Thaana.

Each thought has three lines. The Plan line says what the reply will do.

Correct Thaana gives the correct meaning

If this explanation is correct, the quality of the Thaana controls the result. The data agrees. When the model writes the correct Thaana, the reply gets the gist every time. When it writes incorrect Thaana, the reply gets the gist 61% of the time. Its Thaana is correct about 40% of the time. That is the next thing to train.

Errors that remain

Someone typed bin heylun for bin helun. Helun means shaking, so bin helun is an earthquake. Heylun means waking up. Our model wrote the Thaana for exactly what was typed. Then it explained how to clear land for building. Flash read the message as a question about earthquakes. In the next round, we teach the model to check if a reading makes sense. If it does not, the model tries a similar word.

Thaana:       ބިން ހޭލުން އެހެނީ ކިހިނެއް
Literal:      how does the earth wake up?
Check:        odd
Likely meant: heylun → ހެލުން (shaking), earthquake
Meaning:      how do earthquakes happen?

The next round also teaches chat shorthand. vvv reethi is varah varah varah reethi, which means very very very pretty. The model read vvv as "that's why".

Both models invent facts. We asked for today's date. Our model said 22 May 2025, and Flash said 30 March 2026. The correct date was 7 October.

4-bit weights change the results

At full precision, longer replies increased the score by 25 points. The 4-bit copy got no increase. Its long replies repeated in loops and put Latin letters into Thaana words. If you measure a small language on a quantized model, check for this first.

The opposite is also true. Adapters that we trained on 4-bit weights got worse at full precision. They put Korean and Bengali letters into replies. The adapter that we trained at full precision from the start was the best.

What we learned, and what we do next

The model already has the Dhivehi. It can't reach it from Latin letters. Thaana first took the gist from 42.5% to 87.5% with no new facts in the training data. So for reading chat, access is the problem, and more knowledge is a second step. Next, we instruction-tune the pretrained Gemma ourselves, with an open English recipe (Tülu and OLMo) and our Dhivehi data. Our tests found that the pretrained model reads Thaana better than the instruction-tuned one, so some access may be lost in Google's instruction tuning.

Spelling is now the bottleneck. Correct Thaana gives the gist every time, and the model writes correct Thaana about 40% of the time. Better spelling should give most of the remaining gain. Next, we give the model a dictionary tool and a list of known words. If a spelling is not a known word, the model finds the nearest known word, for example nidhan → ނިދަން. Spelling has one correct answer, so a script can score it, and we use that score as a reward for reinforcement learning (GRPO).

Copied reasoning doesn't copy knowledge. Flash's thoughts taught Gemma to give word-by-word meanings, but Gemma didn't know the words. The Thaana-first thoughts worked because every line came from data that we can check. So we only train on thoughts that a script or a dictionary can check.

The model trusts the letters more than the meaning. It read bin heylun exactly as typed, and the result made no sense. Next, we train it to check if a reading makes sense, and to try a similar word if it does not. GPT-6.1 sol, GPT-6 luna and GPT-6 astra write these traces, with typos and chat shorthand.

The model doesn't know what it doesn't know. Both models invented today's date. When our model doesn't know something, it often repeats itself in a loop, and that loop is a free signal. Next, we train on pairs with DPO. The preferred reply says that it can't check, or it searches first. The rejected reply is the loop or a confident guess. We also put the model in an agent harness with web search, the dictionary and translation, so it can find facts and doesn't have to guess them.

Limits

  • The step-by-step numbers use the 40 messages that we developed against. The comparison with Flash uses 200 held-out messages.
  • The judge was gpt-6-luna. It agreed with my blind ratings on about two thirds of replies.
  • This test measures how well a model reads casual Latin-typed chat. Flash knows much more and writes better Dhivehi.
  • Setup: Gemma 4 26B-A4B with a LoRA adapter; about 2,700 Thaana-first thinking rows, 4,300 synthetic chat rows, 1,500 fiction exchanges and 400 English replay rows; one epoch; we checked every row for overlap with the test.
