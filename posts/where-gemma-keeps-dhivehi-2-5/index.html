Each training example pairs a prompt with a document passage; the service trains on the last assistant reply. This is a separate run from the plain-text continued pretraining on the base model. These samples come after M1c’s CPT stage, before further instruction tuning.

Data. 46,641 rows; 24.45 million target tokens, including 10% English. Mostly Dhivehi fiction and news, plus formal text, Wikipedia, Latin comments and sentences. Sources include Nau-AI’s research-use corpus, d3b4g’s corpora and sentence datasets. The data builder filters out evaluation material. This post contains no source passages or private chat messages.

Comparison. Four newly written synthetic openings. Both models receive “Continue this text” and the same opening in Gemma’s chat template, thinking off. Temperature 0.7, top-p 0.9, repetition penalty 1.1, seed 17, maximum 1,024 tokens. Both models stopped naturally on all four. No script ban. Excerpts preserve the first two non-empty lines; expand for the unedited output. My comments on prose and grammar are my reading as a Dhivehi speaker. The character count is a separate mechanical check.

Decoding. The eight adapted samples use the same four openings at temperatures 0.7 and 1.0. The greedy excerpt used a plain-text prompt; it is not a controlled comparison of the penalty alone. The matched stock-versus-ours comparison above holds the format and settings fixed.

Copying check. I searched for exact five-word runs, ignoring punctuation and spacing, across the training targets and source documents. I then inspected the closest matches. A looser search using two-word runs found no convincing near-copy. This cannot rule out paraphrase or copying from Gemma’s original training data.
